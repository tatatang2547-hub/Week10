# Python Modules Exercise (Week 10)

โปรเจกต์นี้เป็นการทดลองใช้งาน Modular Programming ในภาษา Python โดยแบ่งเป็น 10 โมดูลย่อย และดึงมาประมวลผลร่วมกันใน `main.py`

## โครงสร้างโปรเจกต์
* `main.py` - ไฟล์หลักสำหรับรันโปรแกรม
* `module1.py` - ฟังก์ชันบวกเลข
* `module2.py` - ฟังก์ชันทักทาย
* `module3.py` - ฟังก์ชันสุ่มตัวเลข
* `module4.py` - ฟังก์ชันแปลงอุณหภูมิ C เป็น F
* `module5.py` - ฟังก์ชันเช็กเลขคู่/คี่
* `module6.py` - ฟังก์ชันคำนวณพื้นที่วงกลม
* `module7.py` - ฟังก์ชันจัดฟอร์แมตเงิน
* `module8.py` - ฟังก์ชันดึงวันที่ปัจจุบัน
* `module9.py` - ฟังก์ชันหาค่ามากที่สุดใน List
* `module10.py` - ฟังก์ชันกลับหัวข้อความ

## วิธีการรันโปรแกรม
